# semyung-gateway (Claude Code 스킬)

세명대학교 AI 게이트웨이(BAZE/Mindlogic)로 Claude 대화·이미지·영상 생성을 학교 크레딧으로 쓰는 방법을 Claude Code 에 알려 주는 스킬입니다.

## 설치
```bash
npx skills add Youngwoo-m/semyung-gateway-skill -g
```
또는 `skills/semyung-gateway/SKILL.md` 를 `~/.claude/skills/semyung-gateway/` 에 복사합니다.

## 주의

- 모델·가격은 2026-10-15 기준입니다. `/models/`, `/estimate/` 로 최신 값을 확인하세요.
